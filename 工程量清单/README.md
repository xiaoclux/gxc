# 工程量清单及计算书

由广联达导出的三份 Excel 生成：

| 输入 | 内容 |
| --- | --- |
| 绘图输入构件工程量计算书（.xls） | 基础层～第5层各构件图元计算式 |
| 钢筋明细表（.xls） | 各层各构件按直径的钢筋重量 |
| 清单模板（.xlsx） | 73 项清单编码、名称、特征、单位 |

输出 `工程量清单及计算书.xlsx` 含三个工作表：

1. **分部分项工程量清单计算书**：序号 / 项目名称 / 计算部位 / 单位 / 计算式 / 结果，每层每个构件编号一行，每个清单项末行小计。
2. **分部分项工程量清单**：序号 / 项目编码 / 项目名称 / 项目特征描述 / 单位 / 工程量。
3. **编制说明**：数据来源、取值规则、各项推导说明及“需补充”项。

重新生成：

```bash
pip install xlrd openpyxl
python3 build_qty_list.py 工程量清单及计算书.xlsx <源文件目录>/
```

源文件目录下需包含 `3c2df904-________.xls`、`93d01613-_____.xls`、`4c1dcb22-__.xlsx`（或在脚本顶部改名）。
